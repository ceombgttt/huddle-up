## RESPONSIVE SCALING

```css
/* Mobile (default) - Already large */
/* Small phones get slightly smaller text */
@media (max-width: 380px) {
  h1 { font-size: 32px; }
  h2 { font-size: 24px; }
  .primary-btn { font-size: 18px; }
}

/* Tablets - Keep same or slightly larger */
@media (min-width: 768px) {
  h1 { font-size: 40px; }
  h2 { font-size: 32px; }
  .primary-btn { font-size: 24px; }
  body { font-size: 19px; }
}

/* Desktop - Maximum size */
@media (min-width: 1024px) {
  h1 { font-size: 48px; }
  h2 { font-size: 36px; }
  .primary-btn { font-size: 26px; }
  body { font-size: 20px; }
}
```

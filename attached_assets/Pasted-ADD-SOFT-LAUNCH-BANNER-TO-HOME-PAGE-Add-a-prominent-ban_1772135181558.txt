=== FOUNDING MEMBER LOGIC ===

When user clicks "Join as Founding Member" button:

IF user not logged in:
- Redirect to signup page
- After signup, automatically grant:
  * is_pro = true
  * is_founder = true
  * pro_expiry = null (lifetime)
  * Add "⭐ Founder" badge to profile

IF user already logged in:
- Show modal: "You're already a member! Enjoy your Founder benefits."

IF more than 100 users exist:
- Change button to "Join Waitlist"
- Or remove button and show: "Founding Member spots filled! 127/100"

=== CLOSE BUTTON ===

Small X button in top-right corner:
- When clicked, hide banner
- Store in localStorage: softlaunch_banner_dismissed = true
- Don't show again this session
- Show again after 7 days (check timestamp)

On mobile (< 768px):

- Larger text (18px for heading)

- Shorter height (140px)

=== ANIMATION ===

On page load:
- Slide down from top (0.3s ease-in)

In App.jsx, add banner component:

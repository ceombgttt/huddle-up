=== 1. PUSH NOTIFICATIONS (REAL NOTIFICATIONS) ===

Send actual push notifications to user's phone (not just in-app).

NOTIFICATION TYPES:

1. PARTY REMINDERS:
   Title: "Game starts soon! 🏒"
   Body: "Panthers vs Maple Leafs at Rocco's Tacos in 1 hour"
   Action: Opens party page
   Timing: 1 hour before party

2. PREDICTION REMINDERS:
   Title: "Last chance to predict! ⚡"
   Body: "Game starts in 30 minutes. Make your pick!"
   Action: Opens prediction interface
   Timing: 30 minutes before game

3. PREDICTION RESULTS:
   Title: "You won! +350 points 🎉"
   Body: "Panthers won! Your prediction was correct."
   Action: Opens predictions page
   Timing: Immediately after game ends

4. RAFFLE WINNERS:
   Title: "YOU WON THE RAFFLE! 🎉"
   Body: "$100 gift card is yours! Tap to claim."
   Action: Opens raffle winners page
   Timing: Immediately after drawing

5. CHECK-IN NEARBY:
   Title: "Party happening now! 📍"
   Body: "You're near Rocco's Tacos - join the watch party!"
   Action: Opens nearby party
   Timing: When user is within 0.5 miles
   (Requires location permission)

6. FRIEND ACTIVITY:
   Title: "Mike just joined a party 👥"
   Body: "Panthers game tonight - join him?"
   Action: Opens party page
   Timing: Real-time

7. STREAK NOTIFICATIONS:
   Title: "5 game win streak! 🔥"
   Body: "You're on fire! +100 bonus points earned."
   Action: Opens predictions page
   Timing: After 5th consecutive correct prediction

IMPLEMENTATION OPTIONS:

OPTION A: Firebase Cloud Messaging (FCM)
- Free
- Works on iOS and Android
- Easy integration
- Google service

OPTION B: OneSignal
- Free tier available
- Easy to implement
- Good dashboard
- Multi-platform

OPTION C: Custom implementation
- More control
- More complex
- Requires server infrastructure

RECOMMENDED: Use OneSignal (easiest)

SETUP:

1. Create OneSignal account
2. Add OneSignal SDK to app
3. Request notification permission from user
4. Store device token in database
5. Send notifications from backend

PERMISSION REQUEST:

TIMING: Ask on second visit (not first)
MESSAGE: "Get notified about your parties and predictions?"
OPTIONS: [Allow] [Not Now]

SETTINGS:

Add notification preferences in user settings:

NOTIFICATION SETTINGS PAGE:
- [ ] Party Reminders (1 hour before)
- [ ] Prediction Reminders (30 min before)
- [ ] Prediction Results (after games)
- [ ] Raffle Winners (when you win)
- [ ] Nearby Parties (location-based)
- [ ] Friend Activity (when friends join parties)
- [ ] Achievement Unlocks (badges, streaks)

USER CONTROL:
- Toggle each notification type on/off
- Can disable all notifications
- Respects system settings

QUIET HOURS:

Don't send notifications:
- 10:00 PM - 8:00 AM (user's local time)
- Unless explicitly opted in

RATE LIMITING:

Max notifications per user:
- 5 per day (prevents spam)
- Exception: Critical notifications (raffle wins)

ANALYTICS:

Track in admin dashboard:
- Notification sent
- Notification delivered
- Notification opened
- Conversion rate

=== 2. CALENDAR INTEGRATION ===

Let users add parties to their phone calendar.

ADD TO CALENDAR BUTTON:

On party detail page, add button:
"📅 Add to Calendar"

WHEN CLICKED:

Generate .ics file (iCalendar format):

BEGIN:VCALENDAR
VERSION:2.0
PRODID:-//Huddle Up//EN
BEGIN:VEVENT
UID:party-12345@huddleupus.com
DTSTAMP:20250225T120000Z
DTSTART:20250226T190000
DTEND:20250226T220000
SUMMARY:Panthers vs Maple Leafs Watch Party
LOCATION:Rocco's Tacos, 500 E Las Olas Blvd, Fort Lauderdale, FL
DESCRIPTION:Join us for the Panthers game! 12 people going. https://huddleupus.com/party/12345
STATUS:CONFIRMED
SEQUENCE:0
BEGIN:VALARM
TRIGGER:-PT1H
DESCRIPTION:Party starts in 1 hour!
ACTION:DISPLAY
END:VALARM
END:VEVENT
END:VCALENDAR

BEHAVIOR:

iOS: Downloads .ics file → Opens in Calendar app → User taps "Add"
Android: Downloads .ics file → Opens in Google Calendar → User taps "Save"
Desktop: Downloads .ics file → User opens in calendar app

EVENT DETAILS:

TITLE: "[Team] vs [Team] Watch Party"
LOCATION: "[Venue Name], [Address]"
START TIME: Game time
END TIME: Game time + 3 hours
REMINDER: 1 hour before
DESCRIPTION: "Join us at [Venue]! [X] people going. View party: [link]"

CALENDAR SERVICES:

Also provide direct links:

GOOGLE CALENDAR:
https://calendar.google.com/calendar/render?action=TEMPLATE&text=...

OUTLOOK:
https://outlook.live.com/calendar/action/compose?subject=...

APPLE CALENDAR:
Use .ics file

YAHOO CALENDAR:
https://calendar.yahoo.com/?v=60&...

Show options modal:
"Add to Calendar"
- Apple Calendar
- Google Calendar
- Outlook
- Yahoo Calendar
- Other (.ics file)

UPDATE CALENDAR:

If party details change (time, venue):
- Can't auto-update (calendar limitation)
- Show notification: "Party details changed! Update your calendar."

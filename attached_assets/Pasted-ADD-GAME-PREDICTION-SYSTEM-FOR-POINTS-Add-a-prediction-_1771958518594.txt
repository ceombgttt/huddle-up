ADD GAME PREDICTION SYSTEM FOR POINTS

Add a prediction/betting feature where users can predict game winners and earn points for correct predictions.

=== WHAT TO BUILD ===

1. PREDICTION INTERFACE

For each upcoming game, add a "Make Prediction" section:

SHOW:
- Both teams with logos
- Game date/time
- "Pick the Winner" options (two buttons)
- Confidence slider (1-10)
- Potential points display
- Countdown to game start
- Submit button

EXAMPLE:
┌─────────────────────────────────┐
│ Panthers  vs  Maple Leafs       │
│  [logo]        [logo]            │
│                                  │
│ Who will win?                    │
│ [Panthers] [Maple Leafs]        │
│                                  │
│ Confidence: ●─────── (5/10)     │
│                                  │
│ Win: +250 points                 │
│ Locks in: 2h 15m                │
│                                  │
│ [Submit Prediction]              │
└─────────────────────────────────┘

2. POINTS CALCULATION

FORMULA:
- Base points: 50
- Multiplier: Confidence level (1-10)
- Total: 50 × confidence

EXAMPLES:
- Pick correctly at 10 confidence = 500 points
- Pick correctly at 5 confidence = 250 points
- Pick correctly at 1 confidence = 50 points
- Pick incorrectly = 0 points (no penalty)

BONUS POINTS:
- 5 correct in a row: +100 bonus
- 10 correct in a row: +250 bonus
- Underdog wins (upset): +200 bonus

3. WHERE TO SHOW PREDICTIONS

ADD TO GAME/EVENT CARDS:
- On home page game listings
- On party detail pages
- In "My Predictions" page (new)

EXPANDABLE SECTION:
- Show "Make Prediction" button
- Click to expand prediction interface
- Shows existing prediction if already made
- Can change prediction until game starts

4. PREDICTION STATES

BEFORE GAME:
- Show prediction interface
- Allow user to pick/change
- Show countdown to lockout

DURING GAME:
- Lock prediction (can't change)
- Show "Your pick: Panthers (5/10 confidence)"
- Show "Game in progress..."

AFTER GAME:
- Show result: ✅ "Correct! +250 pts" or ❌ "Incorrect"
- Update user's points automatically
- Show final score

5. MY PREDICTIONS PAGE

Create new page showing:

UPCOMING:
- All games user predicted
- Current picks
- Potential points

PAST:
- Previous predictions
- Results (correct/incorrect)
- Points earned
- Win rate %

STATS:

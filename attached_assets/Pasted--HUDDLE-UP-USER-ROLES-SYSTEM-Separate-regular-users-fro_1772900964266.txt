# HUDDLE UP - USER ROLES SYSTEM

**Separate regular users from venue owners/managers!** 🏢

---

## 🎯 THE PROBLEM:

You have TWO different types of users:
1. **Regular Users** - Fans who join parties
2. **Venue Owners** - Bar/restaurant managers who create parties at their venue

They need DIFFERENT experiences!

---

## 💡 THE SOLUTION:

**User Role System with 3 account types:**

1. **FAN** (default)
   - Can join parties
   - Can create parties at ANY venue
   - See regular app interface

2. **VENUE_OWNER** (claimed venue)
   - Has access to Venue Hub
   - Can ONLY create parties at THEIR venue
   - Parties automatically linked to their venue
   - See venue management tools

3. **ADMIN** (optional - for you)
   - Can do everything
   - Manage all venues
   - Handle disputes

---

## 🗄️ DATABASE STRUCTURE:

```sql
-- USERS TABLE
CREATE TABLE users (
  id UUID PRIMARY KEY,
  email VARCHAR(255) UNIQUE,
  name VARCHAR(255),
  role VARCHAR(50) DEFAULT 'FAN',  -- 'FAN', 'VENUE_OWNER', 'ADMIN'
  claimed_venue_id UUID,  -- Links to their venue (if venue owner)
  created_at TIMESTAMP,
  
  -- Constraints
  CONSTRAINT check_role CHECK (role IN ('FAN', 'VENUE_OWNER', 'ADMIN'))
);

-- VENUES TABLE
CREATE TABLE venues (
  id UUID PRIMARY KEY,
  name VARCHAR(255),
  address TEXT,
  latitude DECIMAL,
  longitude DECIMAL,
  owner_user_id UUID,  -- User who claimed this venue
  claimed BOOLEAN DEFAULT FALSE,
  plan VARCHAR(50),  -- 'BASE', 'FEATURED', 'PRO'
  created_at TIMESTAMP,
  
  FOREIGN KEY (owner_user_id) REFERENCES users(id)
);

-- PARTIES TABLE
CREATE TABLE parties (
  id UUID PRIMARY KEY,
  game_title VARCHAR(255),
  venue_id UUID,  -- Which venue is hosting
  created_by_user_id UUID,  -- Who created the party
  game_time TIMESTAMP,
  created_at TIMESTAMP,
  
  FOREIGN KEY (venue_id) REFERENCES venues(id),
  FOREIGN KEY (created_by_user_id) REFERENCES users(id)
);

-- VENUE ACCESS TABLE (for managers/employees)
CREATE TABLE venue_access (
  id UUID PRIMARY KEY,
  venue_id UUID,
  user_id UUID,
  access_level VARCHAR(50),  -- 'OWNER', 'MANAGER', 'EMPLOYEE'
  granted_at TIMESTAMP,
  
  FOREIGN KEY (venue_id) REFERENCES venues(id),
  FOREIGN KEY (user_id) REFERENCES users(id)
);
```

## 🔐 USER FLOW - CLAIMING A VENUE:

```
STEP 1: Regular user signs up
├─ Role: FAN
├─ claimed_venue_id: NULL
└─ Can join parties anywhere

STEP 2: User clicks "Claim Your Venue"
├─ Searches for their venue
├─ Selects venue from list
└─ Submits claim request

STEP 3: Verification process
├─ OPTION A: Auto-approve (risky)
├─ OPTION B: Email verification
├─ OPTION C: Manual approval (you review)
└─ OPTION D: Document upload (business license)

STEP 4: Claim approved
├─ User role: FAN → VENUE_OWNER
├─ claimed_venue_id: [venue_id]
├─ venue.owner_user_id: [user_id]
├─ venue.claimed: TRUE
└─ User now has access to Venue Hub
```

// User requests to claim a venue
router.post('/venues/:venueId/claim', authMiddleware, async (req, res) => {
  try {
    const { venueId } = req.params;
    const userId = req.user.id;  // From auth token
    
    // Check if user already owns a venue
    const user = await User.findById(userId);
    if (user.claimedVenueId) {
      return res.status(400).json({ 
        error: 'You already own a venue' 
      });
    }
    
    // Check if venue is already claimed
    const venue = await Venue.findById(venueId);
    if (venue.claimed) {
      return res.status(400).json({ 
        error: 'This venue is already claimed' 
      });
    }
    
    // Update venue claim status
    venue.claimStatus = 'PENDING';
    venue.claimRequestDate = new Date();
    await venue.save();
    
    // Send verification email to venue
    await sendVerificationEmail(user.email, venue);
    
    res.json({ 
      message: 'Claim request submitted. Check your email to verify.',
      status: 'PENDING'
    });
    
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
});

// Verify venue claim (via email link or admin approval)
router.post('/venues/:venueId/verify-claim', async (req, res) => {
  try {
    const { venueId } = req.params;
    const { verificationCode, userId } = req.body;
    
    // Verify the code (sent via email)
    const isValid = await verifyCode(verificationCode);
    if (!isValid) {
      return res.status(400).json({ error: 'Invalid verification code' });
    }
    
    // Update user role
    const user = await User.findById(userId);
    user.role = 'VENUE_OWNER';
    user.claimedVenueId = venueId;
    user.venueVerified = true;
    await user.save();
    
    // Update venue
    const venue = await Venue.findById(venueId);
    venue.claimed = true;
    venue.ownerUserId = userId;
    venue.claimStatus = 'VERIFIED';
    await venue.save();
    
    res.json({ 
      message: 'Venue claimed successfully!',
      user: user,
      venue: venue
    });
    
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
});

router.post('/parties', authMiddleware, async (req, res) => {
  try {
    const { gameTitle, venueId, gameTime } = req.body;
    const userId = req.user.id;
    
    const user = await User.findById(userId);
    
    // IF USER IS VENUE OWNER:
    if (user.role === 'VENUE_OWNER') {
      // They can ONLY create parties at THEIR venue
      if (venueId !== user.claimedVenueId.toString()) {
        return res.status(403).json({ 
          error: 'Venue owners can only create parties at their own venue' 
        });
      }
      
      // Auto-link to their venue
      const party = await Party.create({
        gameTitle,
        venueId: user.claimedVenueId,  // Force their venue
        createdByUserId: userId,
        gameTime,
        createdByVenueOwner: true  // Flag for analytics
      });
      
      return res.json(party);
    }
    
    // IF USER IS REGULAR FAN:
    if (user.role === 'FAN') {
      // They can create parties at ANY venue
      const party = await Party.create({
        gameTitle,
        venueId,  // Any venue they choose
        createdByUserId: userId,
        gameTime,
        createdByVenueOwner: false
      });
      
      return res.json(party);
    }
    
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
});

const requireVenueOwner = async (req, res, next) => {
  try {
    const userId = req.user.id;  // From auth middleware
    const user = await User.findById(userId);
    
    if (user.role !== 'VENUE_OWNER') {

      });
    }
    
    next();
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
};

// Middleware to check if user owns the specific venue
const requireVenueAccess = async (req, res, next) => {
  try {
    const userId = req.user.id;
    const venueId = req.params.venueId;
    
    const user = await User.findById(userId);
    
    if (user.claimedVenueId.toString() !== venueId) {
      return res.status(403).json({ 
        error: 'You do not have access to this venue' 
      });
    }
    
    next();
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
};

function VenueClaims() {
  const [pendingClaims, setPendingClaims] = useState([]);
  
  useEffect(() => {
    loadPendingClaims();
  }, []);
  
  const approveClaim = async (venueId, userId) => {
    await fetch(`/api/admin/approve-claim`, {
      method: 'POST',
      body: JSON.stringify({ venueId, userId })
    });
    loadPendingClaims();
  };
  
  return (
    <div className="admin-claims">
      <h1>Pending Venue Claims</h1>
      
      {pendingClaims.map(claim => (
        <div key={claim.id} className="claim-item">
          <h3>{claim.venue.name}</h3>
          <p>Claimed by: {claim.user.email}</p>
          <p>Date: {claim.claimRequestDate}</p>
          
          <button onClick={() => approveClaim(claim.venue.id, claim.user.id)}>
            Approve
          </button>
          <button onClick={() => rejectClaim(claim.id)}>
            Reject
          </button>
        </div>
      ))}
    </div>
  );
}
